# 认知方法论、原子萃取与知识织网规范

知识库拒绝机械堆砌碎片材料，所有入库文献须经结构化透镜研判、一事一卡原子提纯与主题地图编织。本规范确立思维模型调用、认识论分类、原子萃取边界与知识地图（`MOC`）织网准则。

## 1. 思维模型周期表与动态化合

- [methodology.yaml](../dicts/methodology.yaml) 是全库思维模型与萃取透镜的唯一事实源（SSOT），仅收录不可再分的正交基础模型（如第一性原理、控制二分、演进脉络、系统反馈等）。
- 智能体在编织知识地图（`MOC`）或撰写交付成果（`Artifact`）时，按课题特征调取 `1`～`2` 个思维模型组织叙事视角，严禁凭空捏造字典外的伪模型名称，亦不得借视角选择剪裁或扭曲客观事实。

## 2. 认识论真理四分类与演化

全库原子卡（`22-Atomics/`）必须标注明确的认识论属性 `type`：

1. **`OBJ`（客观事实与确定性工程规范）**：科学定律、数学证明、实测基准数据，以及正式发布的行业技术标准、协议格式与确定性接口规范。
2. **`SUB`（主观洞察与架构权衡）**：专家经验、设计哲学、工程折中取舍（Trade-offs）与选型判断。
3. **`SYN`（综合推导与演进洞见）**：跨多源文献或跨领域交叉验证得出的综合性结论与范式演进洞见（`MOC` 固定为 `SYN`）。
4. **`HYP`（待证假说与前沿探索）**：尚未经实测或工程闭环验证的推演与假设，获得实证后可升阶为 `OBJ` 或 `SYN`，被证伪则置为 `deprecated` 并保留判据。

## 3. 原子萃取透镜与同监督域可见性边界

- **两阶段解构与透镜适配**：长篇文献优先经自适应切片生成 `24-Slices/` 物理切片簇与 `TOC-` 树形骨架，再按原料文类匹配专业萃取透镜、常识过滤与动态配额提炼原子命题；严禁将原文目录简单拆段充当原子卡。
- **同监督域可见性与证据隔离**：
  - 在同一监督域内，允许引用本域 `pending` 文献或切片产出 `pending` 候选原子卡；
  - **跨域与隐私红线**：严禁引用外域 `pending` 材料、`private: true` 私有证据、`05-Journal/` 日记或 `30-Workbench/` 未采收草稿作为原子卡证据；跨域引用外域已公开 `active` 文献时严禁回改外域原文；
  - **切片即封口（`processed: true`）与开放式萃取解耦**：`note-slice` 算子对 `library`（或 `artifact`）完成切片解构并生成 `TOC` 与切片簇后，自动将源文档置为 `processed: true`（此后原文封存只读）；后续按不同主题或透镜进行的开放式原子萃取均围绕 `24-Slices/` 进行，不再回改父文献。

## 4. 知识地图（`MOC`）宏观叙事与事务织网

- **综述优先于索引**：知识地图（`23-MOC/`）必须包含连贯的领域综述、机制对比、权衡边界、L1–L5 认知分层与四层下钻阅读路径，用真实原子卡作为论据支撑，严禁退化为仅有双链列表的目录拼接。
- **收尾必含逻辑闭环评估与扩展研究建议**：每张 `MOC` 末尾必须保留并由智能体实质性填写 `## 逻辑闭环评估与扩展研究建议`（包含：① 结合 `OBJ / SUB+SYN / HYP` 分布做**逻辑闭环自检**；② 明确指出形成闭环**还缺哪些内容（Knowledge Gaps）**，如一手实测基准、反例边界或上下游衔接卡；③ 提出 2–4 条可执行的**建议扩展研究内容**，供人类拍板后转入采集或新开子课题）。
- **自主漫游创建 MOC（Autonomous Roaming）**：智能体可通过 `moc-sync --mode roam` 只读扫描本域尚未被任意 `MOC` 正文收录的活跃原子卡，按共享标签与双链连通性发现成熟主题簇（默认 `>= 3` 张）；随后从枢纽卡出发，结合 `note-search --mode deep`（入出链 Top 3）与 `note-get` 自主漫游实读簇内卡片、选定 1–2 个思维模型，调 `moc-sync` 织网并用 `note-update` 补齐顶部综述与底部逻辑闭环缺口分析。
- **可见性与冻结守则**：`MOC` 仅纳入本域内 `status: active` 且非私有的卡片（`20-AI-Zone/` 公共地图严禁穿透纳入私有课题卡片；私有课题内建图自动继承 `private: true`）。
- **单向织网事务**：生成或刷新 `MOC` 时，仅单向更新 `MOC` 正文收纳清单（不回写原子卡 YAML），同时保留人类/智能体在受管块上下撰写的综述与闭环建议段落不被覆盖。发现局部证据断层时在地图中留存研究盲区倡议，不擅自越界联网。
