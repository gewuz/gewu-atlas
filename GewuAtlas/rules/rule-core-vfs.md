# 虚拟文件系统、目录拓扑与命名防撞规范

本规范约束 `GewuAtlas` 在独立数据卷 `Volumes/GewuAtlas-data` 下的目录拓扑、逻辑句柄零路径盲化、子目录准入边界、同名防撞策略及原件/工作台保护红线。

## 1. 独立数据卷与面向智能体零路径输出

- 知识库物理数据存放在独立数据卷 `Volumes/GewuAtlas-data/<vault>/` 下，与 `GewuAtlas/` 程序目录物理分离；新建知识库省略槽位标识时自动分配盲化目录槽位。
- 每个知识库按 [layout.yaml](../dicts/layout.yaml) 展开标准分形骨架，严格禁止路径穿越（`..`）与符号链接越界。
- **零路径外泄铁律**：所有门面返回与状态胶囊仅暴露不透明短句柄（`vlt_XX`、`prj_XX`、`nte_XX`、`slp_XX`、`trs_XX`）、句柄封签与展示标题，**严禁向标准输出暴露物理相对路径、回收站内部路径或宿主绝对路径**（收件箱与附件导入仅返回受控文件名 `file_name` 槽位，不暴露所在目录）。新建知识库完成后应引导用户开启新对话以隔离初始化参数上下文。

## 2. 子目录白名单与强制扁平区红线

在固定骨架分区（`Zone`）内部，普通业务文件夹（`--subdir` / `--target_subdir`）受严格拓扑白名单约束：

1. **允许创建与迁徙子目录的 5 个分区**：`dropzone`（`00-DropZone/`）、`library`（`20-Memory/21-Library/`）、`slices`（`20-Memory/24-Slices/`）、`workbench`（`30-Workbench/`）、`archives`（`99-Assets/98-Archives/`）。
2. **强制扁平、严禁任何子目录的 4 个分区**：`atomics`（`20-Memory/22-Atomics/`）、`moc`（`20-Memory/23-MOC/`）、`slip`（`25-Slip/`）、`attachments`（`99-Assets/10-Attachments/`）。
3. **系统保护目录与根台账**：受保护骨架目录名与课题根台账 `Manifest-*.md` 禁止通过业务子目录接口覆盖、移动或软删；`20-AI-Zone/` 禁止裸建空占位卡。

## 3. 日记区（`05-Journal/`）只归档不删除铁律

- **人机双区隔离**：每日日志固定采用 `# 人类记录` 与 `# AI日志` 双一级标题模板及 `private: true`；智能体追加日志只准写入 `# AI日志` 区，严禁改写、重排或删除 `# 人类记录` 正文。
- **永久留存、只归档不删除**：超出近期保留窗口（默认 `14` 天）的日记仅允许按 `05-Journal/YYYY/MM/YYYY-MM-DD.md` 月度目录归档；全生命周期**严禁对日记执行软删、跨区移出、废弃、升阶删源、外拷、30 天清理或撤回销毁**。
- **整库软删边界**：整库删除仅允许保留全部内容的整库软删并支持恢复，整库物理清除已停用，任何自动化操作不得绕过日记永久保留规则。

## 4. 笔记水位、命名契约与碰撞三策略

- **句柄水位单调递增**：笔记句柄登记表维护独立的 `last_note_seq` 水位；软删只移除活跃映射而不降低水位，任何新建卡片绝不复用历史已分配编号。
- **命名与防撞底线**：
  - 同目录物理路径严禁同名静默覆盖（独占创建 `O_EXCL`），跨目录允许存在同名文件（如各课题独立持有 `README.md`）；
  - `25-Slip/` 书签卡片与 Agent 创建的 `22-Atomics/`、`23-MOC/`、`10-Artifacts/` 统一采用域内编号命名（`Atom/MOC/Art/Slip-<pid>-<seq>-<slug>.md`），`25-Slip/` 支持最多 `5` 层嵌套且禁止环路。
- **升阶与入库碰撞三策略**：
  1. `abort`（默认中止）：目标已存在同名活跃卡片时立即阻断，零覆盖；
  2. `supersede`（迭代替代）：旧卡置为 `deprecated`、注入废弃横幅并移入所在域 `97-Attic/`，新卡写入 `supersedes` 反向溯源，同步级联更新全库引用；
  3. `merge`（合并正文）：经智能体语义研判合并正文后保留演进链，任何策略均不得静默丢失原文。

## 5. 重名摄入、原件冷归档与工作台豁免

- **重名摄入原则**：同名先核对、默认不覆盖；新产物先验证、旧资产后处置；历史须可恢复、附件须确认无其他引用。
- **原件与附件归宿**：PDF、Office、网页等原始文档经多模态转译入 `21-Library/`（或工作台 `source/`）后，原始二进制文件按月冷存至 `98-Archives/`；正文内插图统一扁平存入 `99-Assets/10-Attachments/`。
- **工作台初始化与受控块保护**：新建知识库或课题时，`30-Workbench/` 默认仅创建 `README.md`，任务子目录与个人研究空间（`ws-<agent>[--<task>]`）按需懒创建；预设扩建仅通过 `<!-- atlas:workbench-preset:begin --> ... <!-- atlas:workbench-preset:end -->` 受控块更新导览，遇到无受控标记的人类已编辑 `README.md` 立即阻断，严禁覆盖手写内容。
