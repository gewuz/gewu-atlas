# 双链、短链接与因果编织规范

链接构成知识库的语义网络。本规范定义双链书写语法、别名闭环、双向溯源契约、文件与文件夹搬迁时的链接级联机制及死链治理边界。

## 1. 短链接与管道别名语法

- **双方括号链接**：库内互链使用标准 `[[卡片名]]`；当卡片带有领域前缀或消歧路径时，在正文中优先使用管道别名语法 `[[目标全名|自然概念名]]`，外侧与汉字之间保留 `1` 个半角空格。
- **严禁包裹反引号**：正文中引用卡片或实体必须直接裸写 `[[...]]`，严禁在其外层包裹反引号（反引号会将链接降级为普通行内代码并切断图谱拓扑）。代码围栏与行内代码中的示例文本不作为真实双链解析或改写。
- **跨目录同名消歧**：正式知识资产区若出现指向全库多个同名文件的裸短链，链接体检将报告同名歧义，禁止脚本按字母序盲猜跳转目标，须由智能体或人类消歧。
- **冷归档原件禁链**：`98-Archives/` 下的冷备原件不在正文中建立动态双链，仅在文献 `original_file` 字段以纯文本记录文件名，防止冷备迁出后产生悬空死链。

## 2. 别名闭环

- 同义词、英文缩写与自然概念短名统一登记在卡片 YAML 的 `aliases` 列表中，与正文管道别名 `[[卡片全名|概念短名]]` 形成闭环，无需为同一概念的每种叫法重复建卡。
- 检索命中 `aliases` 时按等价概念归并，不在回答或萃取中误判为新概念。

## 3. 双向溯源闭环

- **原料与原子卡双向溯源**：原子卡通过 `source` / `sources` 与 `provenance` 向上追溯客观文献、切片与 `TOC` 目录树；文献与 `TOC` 通过 `extracted_to` 反向记录全部衍生原子卡。
- **演化替代闭环**：迭代更新成对出现，新卡 `supersedes` 指向旧卡，旧卡 `superseded_by` 指向新卡。
- **知识地图与原子卡闭环**：知识地图（`MOC`）正文收纳域内活跃原子卡，原子卡 YAML 的 `map` 字段反向记录所属知识地图，由事务同步保障双向一致。
- **书签批注双向闭环**：正文 `==@指令==`（兼容全半角 `＝`/`＠` 及历史 `@@...@@`，普通 `==高亮==` 不触发）书签提交后替换为 `[[Slip-...|原书签文本]]`，`25-Slip/` 卡片将原书签存入 `aliases` 并在卡片内回链 `[[source]]`；删除书签卡片须先预览入向引用，获人类批准后才同步清理全库 `[[Slip-...]]` 并软删入回收站。

## 4. 搬迁与软删的双链级联及降级

- **文件夹与单卡搬迁级联**：文件夹整体搬迁先重绑原路径前缀下整个子树的 `nte_XX` 句柄，再按统一的旧址到新址映射一次性重算 Markdown 双链、相对链接与 `.canvas` 画布节点（保留锚点与管道后的显示别名，同目录互链不重复重算，历史日记保持原文）。
- **软删引用门禁與纯文本降级**：软删文件或受控子目录时，若存在入向双链或画布引用，默认阻断并触发 `INPUT_REQUIRED` 预览门禁；经人类确认选择 `downgrade` 后，方可将入向双链与画布节点安全降级为纯文本展示名再移入回收站。

## 5. 隔离、死链与孤岛处置

- `status: pending`、`status: deprecated` 与 `private: true` 的卡片遵循检索与织网隔离：待审卡与废弃卡不织入正式知识地图，私有卡不穿透至公共域。
- 链接体检与拓扑报告中的悬空死链与孤岛卡仅作治理信号，严禁由算子自动删除孤岛卡片或静默抹除疑似死链；死链须先区分是目标改名、目标废弃还是人类主动删除（人类删除遵循状态 2 清理引用方断链，绝不复活被删文件）。
