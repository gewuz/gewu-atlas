# 状态、容器与身份三元正交公理

知识库中任意知识实体的存在由**状态维、容器维、身份维**三个正交维度描述。禁止用目录移动表达废弃、用文件名表达审核状态或用物理位置代替认知定性。

## 1. 三元正交定义

1. **状态维（真理性生命周期）**：由 `status` 承载，取值为 `pending`（待审候选）、`active`（已核验生效）、`deprecated`（已淘汰/证伪）。
2. **容器维（物理分形域与分区）**：由所在自治域（`20-AI-Zone/` 公共域或 `30-Projects/<id>/` 课题域）及域内固定功能舱位（`21-Library`、`22-Atomics`、`23-MOC`、`24-Slices`、`10-Artifacts`、`25-Slip`、`30-Workbench`、`97-Attic`）承载。
3. **身份维（认知定性与溯源）**：由认识论属性 `type`（`OBJ` / `SUB` / `SYN` / `HYP`）、署名三元组（`created_by` / `updated_by` / `reviewed_by`）、课题归属 `project_id` 及演化替代链（`supersedes` / `superseded_by`）承载。

三个维度独立变化：改变其中一个维度不自动篡改其余两个维度。

## 2. 状态维流转与冻结守则

- **待审与转正**：`status: pending` 的卡片禁止直接跨区升阶（`promote`）或织入正式知识地图（`MOC`），必须先经人工或受控校验将状态转为 `active`。
- **淘汰与废弃**：知识被证伪或被新卡迭代时，将 `status` 置为 `deprecated`，在正文顶部注入标准 `[!WARNING]` 废弃横幅，并填写 `superseded_by`；默认归入所在域 `20-Memory/97-Attic/`，其废弃语义仍由自身 `status: deprecated` 标志承载。
- **同构域冻结拦截**：当课题台账 `Manifest-*.md` 处于 `archived` 或 `deprecated` 冻结状态时，算子对一切向该域的萃取、审批、织网、双链、切片、采收、定稿、发布及文件迁入执行写前硬阻断（`E_DOMAIN_FROZEN`）。

## 3. 容器维分形同构与课题生命周期

- **公共域与课题域同构**：`20-AI-Zone/` 与每个 `30-Projects/<id>/` 共享完全相同的分形子目录骨架。在课题域内执行切片、非原子卡升阶、知识地图同步与卡片废弃时，产物默认留在本课题域内，不污染 `20-AI-Zone/`；仅课题内已处于 `active` 的原子卡执行升阶时，才向上晋升至 `20-AI-Zone/20-Memory/22-Atomics/`。
- **可见性与退网脱链**：私有课题（`private: true`）内的卡片默认隔离，不穿透进入公共域知识地图；课题退网（`unpublish`）或软删时自动审计并安全脱链，恢复公开（`publish` / `restore-links`）时按快照还原引用。
- **合并、拆分与快照保护**：课题合并与拆分采用双阶段目录指纹快照（`snapshot_version: 2`），记录前置镜像与操作后指纹；工作台重名文件默认追加 `-from-<源课题>` 后缀双份保留，并在合并/拆分产物写入 `combined_from` / `split_from` 溯源；后续若发生新增、修改、删除或外部引用变更，撤回操作立即触发 `E_UNDO_CONFLICT` 拦截，严禁静默覆盖。

## 4. 变更收敛三问

执行任何卡片或容器变更前，必须独立核对以下三项：

1. **真理结论是否改变**：若改变，更新 `status` 与迭代链（`supersedes` / `superseded_by`）；未变则保持原 `status`。
2. **知识角色或归属域是否改变**：若改变，经受控算子迁移分区或升舱；客观文献沉淀出原子卡时，文献本体留在 `21-Library/` 不移动。
3. **认知定性或审核溯源是否改变**：若改变，更新 `type` 或审核署名字段；未变则保持原值。

## 5. 交付成果（Artifact）准入与日记认知隔离

- **成果两阶段准入**：`10-Artifacts/` 仅接纳经工作台采收（`stage: draft`）与正式定稿（`stage: final`）的高维交付物；严禁通过普通文件复制或回收站恢复将任意笔记直接塞入 `10-Artifacts/`。
- **日记不等于知识定论**：`05-Journal/` 记录日常线索与工作日志，固定为 `private: true` 且不携带真理性 `status` 字段；日记内容不得直接作为已核验知识参与原子卡审批、自动切片、自动织网或随课题公开。
