# Markdown 分级排版与文本写作规范

本规范定义 `GewuAtlas` 产出或修订一切 Markdown 文本（规则、技能、原子卡、知识地图、交付研报、工作台笔记与对话长文）的排版与行文基线。与规范技能 [atlas-style](../skills/atlas-style/SKILL.md) 协同生效，兼顾脚本零歧义解析与人类高可读性。

## 1. 结构复杂度三档分级（Formatting Tiers）

所有文档统一以标准纯文本 Markdown（配可选 YAML Frontmatter）为唯一载体，核心结论不得依赖特定客户端私有扩展才能阅读：

1. **Tier 1 协议层（`AGENTS.md`、`rules/`、`skills/`）**：
   - 机器与智能体解析优先级最高，追求零结构歧义；
   - 各级标题与段落之间保留且仅保留 `1` 个空行；无序列表统一用 `-` 且子级固定缩进 `2` 个半角空格（禁用 Tab）；代码块必须显式标注语言标签（`bash`、`yaml`、`json`、`text`）；
   - 允许单层紧凑 GFM 路由/对照表；禁用跨行跨列合并表、内联 HTML 标签（如 `<br>`、`<div>`、`<span>`）、多层折叠 Callout 与多余表情装饰。
2. **Tier 2 蒸馏层（`22-Atomics/`、`23-MOC/`、`21-Library/`、`24-Slices/`）**：
   - 聚焦单一命题或专题因果证据链，双链致密；
   - 图表优先采用纵向自上而下的 `flowchart TD`（节点标签控制在 `10` 字以内，严禁在节点内塞入 `<br/>` 或未转义方括号），防止横向宽图在窄视口下被拉伸失真；
   - 允许 `2`～`4` 列轻量对照表与单层标准 Callout（`> [!NOTE]`、`> [!WARNING]`）。
3. **Tier 3 叙事层（`10-Artifacts/` 交付研报与综合专题报告）**：
   - 面向人类高维决策，全面支持多列表格矩阵、可折叠 Callout（`> [!NOTE]-`）、`sequenceDiagram`、`stateDiagram-v2`、`erDiagram` 与多模态插图结构化注释。

## 2. 中西文混排、留白与标点冲突熔断

- **盘古空格留白**：汉字与英文字母、半角数字、行内代码（`` `cmd` ``）或链接外侧之间保留 `1` 个半角空格；数值与度量单位间保留半角空格（如 `16 GB`、`200 ms`），`%` 与 `℃` 紧贴数值。
- **行内修饰符标点外置熔断**：
  - CommonMark 解析器在 `**...**`、`~~...~~` 内侧紧贴全角标点（`“”`、`「」`、`（）`、`《》`、顿号、逗号）时易导致闭合失效；
  - **`**` 内侧首尾必须紧贴汉字、字母或数字**：成对全角引号、括号、书名号一律移至加粗定界符外侧（如 `「**核心概念**」`、`**扩展模式**（Extended Mode）`）；若跨度内含超过 `2` 个全角标点，取消整段加粗，仅加粗内部核心词。

## 3. 标题序号互斥通道与量词禁令

1. **三通道互斥**（单篇文档只选其一，禁止混用）：
   - 西式数字通道（`1.` → `1.1` → `1.1.1`）；
   - 中式汉字通道（`一、` → `（一）` → `1.`）；
   - 无序号纯概念通道。
2. **量词修辞禁令**：严禁在标题与纲要中拼凑“三大原则”“四大支柱”“五步走”“八大核心”等修辞凑数。
3. **标题行末净化**：各级 Markdown 标题行末不加句号、逗号、冒号、分号或叹号。

## 4. 全局文本反模式熔断

- **剥离报幕与套话**：使用平实冷静的同行专家语态，禁止“非常荣幸为您解答”“综上所述”“总而言之”“显而易见”“未来可期”等空洞串场与尾部升华；首句直切结论，答完核心依据与未决边界即停。
- **禁止虚构二元对立与凑数排比**：禁用“不是 X，而是 Y”“与其说 X，不如说 Y”句式；有几条事实依据就列几条，不硬凑三段排比；禁用“底层逻辑”“深度赋能”“协同共生”“颠覆性”等空洞黑话。
- **循证融会成文**：问答与综述须将多源证据按“核心界定 → 机制与因果链 → 权衡与适用边界”自然融会成文，严禁把检索结果按“卡片 A 说……卡片 B 说……”机械罗列拼盘。
