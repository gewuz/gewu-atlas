# PDF：双引擎与语义校对

默认脚本按横竖版比例选择论文或幻灯片引擎；可用 `--pdf_mode paper|ppt` 指定。支持文字、代码保护、图片提取、目录/页眉页脚过滤、跨页段落与表格整理。书签优先确定标题；书签不足时退回编号文法与字号聚类，保留告警。长文按章节组装，扫描件保留图片。

可选 `--dpi` 设置图片渲染分辨率，`--skip_decorative true` 按大小与尺寸阈值过滤装饰图。不保证自动过滤所有页眉或复杂版式无误，不把脚本提取等同语义正确。

仅在 deep 或用户要求校对时：

1. 核对书签、候选标题与层级，避免强调句被误判标题、编号重复；保留作者合理留级。
2. 检查跨页断词、段落粘连、列表续接和代码缩进，原代码与公式不作无依据修订。
3. 逐表核对跨行/跨列表头、合并单元格、单位、合计与脚注；不得从几何填充推断业务关系。
4. 全图按主技能四轮检查；扫描图看不清时标未知，不能由文件名推测正文。
5. 对照原文术语、数据和引用，长文用 fmt-window 持续至尾部，核验接缝。

边界：默认无 OCR；加密/损坏文档报告失败；复杂多栏、手写与浮动版式需视觉复核。保留原件，无法核实的标为未完成。

职责与调用总则以 [atlas-fmt](../SKILL.md) 及 [commands.yaml](../../../dicts/commands.yaml) 与 [rule-core-vfs.md](../../../rules/rule-core-vfs.md) 为准。本参考的语义加工步骤仅在 deep 或明确要求相应加工时执行。
