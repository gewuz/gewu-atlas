# Word：OpenXML 转换

默认脚本支持标题1–6级、numbering.xml 动态多级序号、加粗/斜体/删除线/行内代码、等宽连续代码块、gridSpan/vMerge 合并表格平铺、word/media 内嵌图提取、美元符号保护。输入为 DOCX；旧 DOC 需另存 DOCX/PDF。

深加工逐窗核对：编号重启与连续性、显式序号是否重复、样式的真实含义、代码边界和缩进、合并表的列对应及合计、图像与正文的关系、术语和单位。图片导读/独立伴生卡按主技能，不在默认转换后自动添加。

修订痕迹、批注、复杂文本框和浮动版式不是完整支持项；含未接受修订时不得断言输出就是最终版本。加密文档失败即保留原件并报告，不转成空壳交付。

职责与调用总则以 [atlas-fmt](../SKILL.md) 及 [commands.yaml](../../../dicts/commands.yaml) 与 [rule-core-vfs.md](../../../rules/rule-core-vfs.md) 为准。本参考的语义加工步骤仅在 deep 或明确要求相应加工时执行。
