# 应用工程约束基线（gewu.app-engineering-baseline/1）

权威来源：GewuForge 同名契约；版本 1.0.0。Atlas、Ticket 及新生成域携带同字节镜像，随契约分发；更新须同步来源与镜像，不能独立改写。详细设计背景位于 Forge 开发版 references/app-engineering-methodology.md，运行和独立安装不依赖该背景文档或兄弟域目录。

## 适用范围与职责

适用于 GewuForge 与由其生成的格物域。Atlas 负责业务对象、工具和规则，独立运行且不集成 GewuTrack；Forge 的 Track 能力不属于 Atlas 的业务保证。执行保证以 execution-routing-v1.md 声明的路线及实际回执为准。

## 契约边界

- AGENTS 负责作用域与路由；Rule 定义不变量；Contract 定义输入输出、前置、失败、副作用及例外；Skill 组合已存在的调用，不能产生新授权或替代状态机。
- 每个约束指定权威来源和适用范围。源文、实现与测试证据分别记录；发现冲突先报告并修订，不用默认值或文件深度猜测授权。
- 统一入口、四通道参数、逻辑句柄、双态胶囊及高敏升级要求由 rule-app-contract-rail.md 与本域安全配置落实。句柄或密钥可用不代表业务授权。
- 常规 Python 路线不承诺同 UID 对抗隔离或所有内存副本清零。高敏升级需独立权限边界与真实环境验收。SHA-256 摘要比对不构成数字签名；受信摘要的来源与修改权限必须另行保护。
- 系统修订按 sys-change-ticket-v1.md 记录真实授权与起止提交；不把本地声明或审计测试视为人类审批。生成候选不得自动宣告生效。
- 验收分别记录结构检查、接口核对、业务反例与未验证边界；保留失败结果，开发集与独立验证集分离，不反复改答案或削弱断言取得通过。
